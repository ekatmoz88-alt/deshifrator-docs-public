# Описание программы

## Автоматизированное рабочее место по оформлению документов «Дешифратор»

АРМ «Дешифратор» — отдельное настольное приложение, предназначенное для поиска и обработки сведений о персонах и досье, подготовки данных и формирования печатных документов.

По доступным проектным материалам, функциональные области приложения включают:

- пользовательский интерфейс на WPF/WinForms;
- поиск персон и досье;
- работу с данными о делах, документах, адресах и комментариях;
- обмен данными с мобильным модулем, включая импорт, экспорт и синхронизацию;
- SOAP-интеграцию, описанную в проектных материалах;
- адресный поиск с использованием данных ФИАС и Elasticsearch;
- локальное хранение данных с использованием SQLite;
- подготовку печатных представлений и обработку MRZ;
- конфигурацию и журналирование.

Этот перечень отражает содержание доступных материалов и не является утверждением о полноте реализации каждого сценария или интерфейса.
