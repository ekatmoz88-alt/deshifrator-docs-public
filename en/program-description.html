Deshifrator Document-Processing Workstation

Program description and verified scope of the available technical documentation.

Publication scope. This page is based on available project descriptions and selected source-code excerpts. It is not a complete program specification or a full source-code audit.

Program purpose

Deshifrator is a standalone desktop application intended for searching and processing person and case records, preparing data, and generating print-ready documents.

The available project materials describe the following functional areas:

  • WPF/WinForms user interface;
  • person and dossier search;
  • case, document, address, and comment data;
  • file-based exchange with a mobile module, including import, export, and synchronization;
  • SOAP integration described in the project materials;
  • address search using FIAS data and Elasticsearch;
  • local data storage using SQLite;
  • print-view preparation and MRZ processing;
  • configuration and logging.

This list summarizes the available materials. It does not claim that every workflow or interface has been fully verified.
